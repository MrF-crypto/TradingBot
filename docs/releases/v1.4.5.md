# v1.4.5 — 平仓明细、成交对账与组合保护

桌面版「交易明细」、运行日志和导出现在使用同一份平仓记录。选中一笔交易，可以查看当时实际触发的规则、规则参数、触发行情价、触发线和成交均价。点击「导出交易明细 CSV」可逐列核对。

## 平仓复盘

- ATR 移动止盈保留形成退出线时的有效 ATR 和实际倍数。收益率回撤止盈保留启动门槛、峰值收益率、允许回撤的百分点和触发时收益率。同一拍满足多个条件时，明细显示引擎实际执行的规则。
- 平仓回报迟到或程序重启后，核对原委托时沿用首次触发记录。成交均价取自交易所回报。旧记录缺失的数据标为「未记录」，历史估算价在明细中单独标识。
- 智能多单也可自动补录交易所外部平仓。程序在成交查询前后确认已空仓，按原开仓订单核对分批成交、成交均价、已实现盈亏和手续费。历史补账期间，符合策略和当前账户风控的信号仍可开仓。核平后恢复该方向的组合利润计算，BTC 利润划转和购买继续按结算结果及预算条件执行。

## 风控与行情修复

- **硬止损对账**按查询发起时的保护单编号核对。新挂或补挂委托可继续提供保护，迟到的旧查询结果只处理对应的旧单。硬止损成交按交易所确认的成交均价记账。
- **账户熔断**冷却结束后只允许一笔带硬止损的试探开仓。原单成交和保护单均已确认后，恢复常规开仓。重启后按原委托编号核对试探状态。
- **BTC 划转待核**期间，合约开仓按可确认保证金、已预留的划转金额及在途开仓需求进行检查。余额充足的有效信号可以继续入场。
- **备用行情**在主标记价连续三轮没有有效报价后接管。备用期间逐轮尝试主源，主源恢复后切回。状态栏和日志标示价格来源，双源失败时缓存按原报价时间过期。
- **组合市场广度**继续采集已退出候选池的固定样本，状态中可查看有效样本数和缺数原因。确认下架后才从合格候选中补位，保留组合利润峰值和保护阶段。当前一根收盘的缺票足以改变结论时，等待补齐再确认转弱或恢复。

回归用例覆盖 CHIPUSDT 的 ATR 与收益率退出归因、LUNA2USDT 的外部平多补账、保护单回报乱序、熔断期间并发信号、备用行情切换及广度缺数恢复。
