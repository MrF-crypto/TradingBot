# v1.4.1 — 桌面发布包精简修正

修正 v1.4.0 仍在 Windows、macOS 包中附带无头程序和无关配套的问题。本版本调整构建与分发，不修改交易策略、止损、API 配置和断点恢复逻辑。

| 平台 | 解压后的内容 |
| --- | --- |
| Windows x64 | `TradingBot.exe`、实际使用的 DLL、`platforms/`、`licenses/`、空 `data/` |
| macOS Intel / Apple Silicon | `TradingBot.app`、空 `data/`；许可证置于应用包内 |
| Linux x64 / ARM64 | `ccbot_headless`、`config.example.json`、简要 `README.md`、`licenses/` |

- Windows、macOS 不再构建或安装无头可执行程序，桌面包不附带配置模板、工具脚本、整套文档或根目录构建信息。
- Windows 按 GUI 和 Qt 平台插件的传递 DLL 依赖打包，移除未使用运行库；在清理开发环境搜索路径后验证 GUI 能启动。
- macOS 在加入许可证后重新签名，并验证架构、依赖、签名、离线启动及程序旁的数据路径。macOS 运行基线仍为 15.0。
- Linux 保留独立无头程序及部署必需内容，原配置和状态文件格式不变。
- CI 增加最终成品白名单，拒绝桌面包中的无头程序、无关文件和非空 `data/`；测试覆盖传递 DLL 依赖和缺失依赖。
- 构建来源、依赖清单、原生 CI 结果和压缩包摘要单独提供在 Release 的 `BUILD_VERIFICATION.json`；使用 `SHA256SUMS.txt` 校验下载包。

升级前退出旧程序并备份完整数据目录。建议解压到新目录后保留原来的完整 `data`，或在 macOS 替换原 `.app`。不要删除已有 `data`、用空目录替换旧数据或覆盖 Linux 的已有配置；不要同时运行两个实例管理同一账户。旧版本遗留的无头程序、文档和工具不会由新程序自动删除，避免误删用户文件。

[v1.4.0 的组合利润保护与 BTC 积累](v1.4.0.md) 继续保留，两项功能默认关闭。完整使用说明和工具保留在 GitHub 源码仓库。
