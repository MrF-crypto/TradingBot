# v1.4.0 — 组合利润保护与 BTC 现货积累

智能模式设置新增“利润保护 · BTC 积累”页。两项功能均默认关闭，升级后由用户选择启用；原有单币止损、硬止损保护和监控断点继续保留。

## 满仓时的组合利润保护

- 多、空方向分别跟踪本轮已实现与未实现净收益及峰值，无需等持仓数减少才保护利润。
- 使用固定候选群体计算收盘趋势广度。首版使用 1h 周期，至少 10 个候选、有效数据覆盖至少 90%；缺失行情不能被当作趋势转弱。
- 研究初值：本轮峰值达到 100 USDT 后启动保护。广度低于 45% 或较峰值下降 15 个百分点，连续确认 2 根后暂停该方向新增风险；同时利润峰值回撤达到 20% 时退出该方向。硬回撤 35% 不等待广度确认，但需要有效持仓价格。
- 退出过程中暂停所有智能新增风险，仅关闭本程序管理的自动持仓。受保护方向等待广度达到 60%、连续确认 2 根，并出现新的收盘突破后恢复开仓。
- 广度转弱后，若已有单币止损先完成全部退出，也会进入可恢复的等待阶段。

上述参数是可调整的初始值，未经用户实盘数据的收益优化验证；滑点、价格跳变和离线仍可能使实际回撤超过设定值。

## 空头净利润积累 BTC

- 首版支持普通主网、单向持仓、单资产 USDT 合约账户。采用内部划转到现货后买入 BTC，不借款；不支持统一账户自动划转、测试网划转或 1× 永续积累。
- 只使用首次启用后新开且完整平仓的智能空单净收益；按实际成交扣除手续费和资金费，累计亏损先回补，并受整体策略已实现收益和保留合约权益限制。
- 默认分配比例 30%，每批至少 50 USDT、最多 500 USDT；默认等待 BTC 1h EMA20/60 上涨许可，再使用带价格上限的 IOC 限价单买入。
- 首次资金核对保存合约权益作为默认保留额。非 USDT 合约手续费或无法换算的现货手续费会暂停自动购买，避免把估算收益用于分配。
- 需要现货交易和内部划转权限，不需要提现权限。关闭功能会暂停新增购买，已提交请求继续核对，不自动卖出已购 BTC。BTC 价格仍会波动，买入 BTC 不等于锁定 USDT 收益。

## 重启、对账和资金安全

- 原数据目录新增利润账本，保存峰值、广度确认、期初持仓、累计已用额度及划转和订单意图。GUI 文件名为 `ccg_smart_state.json.profit`；headless 为 smart 状态路径加 `.profit`。
- 成交按合约持仓周期配对，重启重新分配机器人编号不会切断开平仓关联。
- 划转或订单超时先核对，不盲目重发；部分成交按实际支出结算，剩余额度保留。后续同金额人工划转不会用来确认早先未知的请求。
- 外部平仓、手动改仓或缺少成交导致数量不一致时，暂停该方向的组合回撤计算与新增风险，保留原有单币止损。
- 账本损坏、账户凭证不匹配或划转无法唯一确认时保留原文件并提示核对，不以删除或清空记录的方式自动恢复购买。

## macOS 启动与升级

包含此前开发版的首次启动改进：优先使用 `.app` 同级 `data/`；遇到只读临时运行目录时自动使用可写目录并记住位置。提供全新配置和恢复旧数据入口，全新配置使用独立凭证身份。设置中可打开实际数据目录。详情见 [macOS 启动说明](v1.3.5.md) 与 [平台说明](../PLATFORMS.zh-CN.md)。

升级前退出旧程序并备份完整数据目录；保留原持仓、监控状态、配置身份和利润账本。不要同时运行两个实例管理同一账户。下载时按 Windows x64、macOS Intel x64 / Apple Silicon ARM64、Linux x64 / ARM64 选择对应包，并使用 `SHA256SUMS.txt` 核验；包内 `BUILD_INFO.json` 标识实际源码提交和 CI。

本版本新增离线回归覆盖广度确认、软硬回撤、退出恢复、重启持仓配对、费用归属、预算回补、部分成交、请求超时、外部改仓与损坏账本。最终原生平台结果与下载附件以对应 GitHub Release 和 CI 为准；没有使用用户真实账户执行测试交易。
