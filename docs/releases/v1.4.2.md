# v1.4.2 — 成交核对、利润账本与换仓预检修复

修复成交均价缺失时使用行情报价记账、重复回执覆盖结算结果，以及组合保护等待期间反复换仓预检和日志刷屏的问题。交易参数默认值保持不变，兼容原有仓位、止损与监控断点；不自动回写历史成交或利润账本。

## 成交与盈亏

- 成交数量和均价必须经过有效性检查。回执缺少均价时，使用交易所累计成交额计算，或查询原订单确认，不再使用行情报价代替成交价。
- 暂未确认的平仓继续核对同一订单，保留原仓位记录与止损，避免重复提交平仓单；迟到回执不触发过期的反手信号。确认部分平仓后继续保护剩余仓位，确认全部平仓后才撤销对应硬止损。
- 已知成交数量但均价未确认的开仓保留风险预留，并按原初始止损补挂交易所保护。核对到真实均价后恢复持仓记录，保持暂停，等待持仓核对及人工恢复。待核对订单信息随断点保存。
- 明细、日志和导出明确区分毛盈亏、预估手续费及预估净盈亏；利润账本使用交易所实结手续费、盈亏和资金费。预估净盈亏不等同于实结净额。明细增加成交价格显示精度，并修正负盈亏的符号显示。

## 利润账本与满仓换仓

- 重复回执和迟到的不确定结果不会清除已有实结金额。
- 成交回执与本地仓位尚未同步时，暂停相关利润计算，避免误报账本不一致；真正缺少对应成交的仓位变化仍会阻止新增风险。
- 引擎仍有待核对的平仓时，即使账本已经结算，也不会提前归集利润购买 BTC。
- 组合利润保护和恢复等待闸门前移，受阻候选不再反复发起换仓预检。失败预检间隔至少 15 秒重试，同品种、同根 K 线的相同取消原因只记录一次；重新勾选换仓功能可立即重新评估。
- 上述新增风险闸门不拦截已有持仓的保护性退出。

## 精简发布包

| 平台 | 解压后的内容 |
| --- | --- |
| Windows x64 | `TradingBot.exe`、必要 DLL、`platforms/`、`licenses/`、空 `data/` |

Windows、macOS 不附带无头程序、工具脚本、配置模板或整套文档。macOS 运行基线仍为 15.0，Linux 为 Ubuntu 24.04。各平台构建来源、验证结果及依赖记录在独立的 `BUILD_VERIFICATION.json` 中，下载摘要见 `SHA256SUMS.txt`。

## 更新说明

本次发布不操作正在运行的实盘程序、配置、数据、仓位或交易所止损单。更新时退出旧程序并备份完整数据目录，再替换程序及必要运行文件，保留原来的完整数据；不要用发布包中的空 `data/` 覆盖旧数据，也不要同时启动两个实例管理同一账户。首次启动后核对持仓、止损与监控恢复状态。历史记录保持原值，新的成交确认逻辑在更新后的运行中生效。
