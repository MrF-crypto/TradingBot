# TradingBot v1.0.0

TradingBot 首个独立版本，基于 CCBot v5.11.0，保留上游历史与 MIT 许可。面向 Binance USDT-M 永续合约，提供 Qt6 桌面版与无界面版。

## 本版变化

- 智能模式仅保留“趋势跟踪”，移除智能裸K埋伏、波动顺势及对应设置和死代码。手动抛物线 SAR、纯裸K继续保留。
- 默认用 EMA20/60 的方向、斜率和分离度识别趋势，以 1h 唐奇安通道收盘突破确认入场；上涨许可做多、下跌许可做空，震荡与过渡状态等待。
- 保留量能、ATR、突破位置与追价限制；分钟级双向异动可唤醒扫描，但仍须满足信号和风险闸门。
- 使用初始止损、只向有利方向移动的追踪止损与反转退出；自动 bot 强制启用交易所初始灾难止损。
- 单笔计划风险、组合风险与同向风险预算共同限制新仓；在途委托占用预算，状态不明的委托保留预留并冻结新增风险，等待订单与仓位核对。
- 精简依赖，GUI 与 headless 共用执行层，新增趋势、风险预算、恢复与异动场景覆盖。
- Windows 便携包使用系统 CA 信任库校验 HTTPS；提供离线版本与 Qt 运行库检查入口。

## 下载

`TradingBot-v1.0.0-windows-x64.zip` 是 Windows x64 便携包，包含桌面版、无界面版、必要的动态库、配置模板、文档和第三方许可证。完整解压后运行 `TradingBot.exe`。`SHA256SUMS.txt` 用于核验下载完整性。包内 `BUILD_INFO.txt` 记录构建工具和运行依赖，`THIRD_PARTY_NOTICES.md` 提供来源与许可说明。

使用 PowerShell 可运行 `Get-FileHash .\TradingBot-v1.0.0-windows-x64.zip -Algorithm SHA256` 并与校验文件比较。程序未做 Windows 代码签名。

Linux/macOS 首版提供源码与 CI 构建检查；此 Release 的已核验下载附件为 Windows x64 包。

## 验证与边界

- Windows x64 Release 构建，GCC 16.2.0、Qt 6.12.0，启用编译警告作为错误。
- 17/17 CTest 测试通过，测试套件注册检查通过。
- 便携包检查动态库闭包、Qt 平台插件加载、两个入口的版本号及文件白名单；添加的配置模板与文档来自已审查的源码文件。
- 未运行真实账户、未提交订单；尚未完成历史回测、样本外测试及实盘盈利验证。默认参数是研究初值。
- 收盘确认与扫描存在延迟，急涨急跌可能错过或触发追价限制；本地风控和交易所止损不保证避免滑点、跳空或损失。

## 升级与配置

智能模式默认关闭。先使用测试网验证；不要把 API 凭证、实际 `config.json`、`data/`、状态或成交日志上传到仓库。

新配置策略名为 `trend_following`，旧 `turtle` 名称仍可读取。旧智能 `bare` / `vol` 配置被拒绝；若旧状态仍有已移除智能策略的持仓，先用旧版本管理至平仓后再升级。不要同时运行两份程序管理同一账户。

详细实现与待研究项见 [趋势跟踪 V1](../TREND_FOLLOWING_V1.zh-CN.md)，运行方式见 [Headless 说明](../HEADLESS.md)。
