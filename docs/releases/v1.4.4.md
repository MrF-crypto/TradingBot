# v1.4.4 — 历史平空自动对账与信号入场

在交易所 App 手动平掉智能模式的空单后，TradingBot 会在后台查询历史成交。即使还有品种等待补账，其他币的有效信号也能按原策略和当前账户风控入场。运行中的智能趋势 bot 确认该币空仓后会继续监控，同币再入场须出现新的有效收盘突破。

## 平仓补录

- 对账以该账户、品种和原开仓订单为起点，在查询历史成交前后各确认一次交易所仓位。程序按实际成交数量、价格、手续费和已实现盈亏核对分笔、分批平仓，核清后写入利润账本。重复重启沿用已有记录。
- 同币在补录前已发生新的交易时，程序会等到该币再次空仓，按已记录的开仓订单分别核对各个周期。历史不完整、成交归属冲突或查询期间仓位变化时，利润状态会显示待核对原因。
- GUI 交易明细按实际平仓时间展示已补录的成交。只有属于当前 UTC 日的补录才计入当日亏损限额。

## 对开仓和利润保护的影响

旧账有差异时，该方向暂停更新利润回撤金额，新的 BTC 利润划转和购买等待结算。已有持仓的止损、已触发的组合保护、持仓上限和每日亏损限额继续生效。账户暂停、当前持仓或委托状态不明时，仍执行相应的开仓限制。

离线回归覆盖七个品种只有六个补齐时的开仓、同币新旧周期归属、分批成交、重复重启、查询期间重新开仓及普通和统一账户的持仓核对。
