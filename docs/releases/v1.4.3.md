# v1.4.3 — 杠杆超时恢复与执行检查修复

设置杠杆超时后先查询交易所实际倍数，已达到目标就重新检查入场条件；无法确认才做有限重试。增加写入开仓意图和利润归集网络等待后的最终检查，避免按已经失效的价格、暂停状态或购买参数继续执行。

## 杠杆与入场

- 普通合约和 Portfolio Margin 均支持按品种查询实际杠杆，包括空仓记录和中文名称合约。查询失败、倍数不符或多条记录冲突时不放行。
- 每轮最多两次设置、两次查询；明确的参数、权限和限流拒绝不立即重试。仍未确认则等待 30 秒重新评估，连续失败不刷屏，不消耗本根 K 线的入场资格。
- 确认后重新读取价格、ATR和止损，计算数量并检查趋势、突破、追价、报价/信号时效、暂停、利润保护及风险预算。重试只针对杠杆设置，不重复发送开仓订单。
- 写入开仓意图账本后再次检查入场计划。等待期间暂停、报价过期、信号失效或预算收紧时，取消该计划、完成同一账本记录并释放预留，避免重启后查询从未发送的订单。

## 利润归集与清理

- 利润划转和 BTC 现货购买在行情查询后重新检查暂停、在途委托、持仓核对和最新配置。资金保留额、单批上限等参数变化时等待重新评估，不继续执行旧计划。
- Windows 账本或断点被短暂占用时，对原子替换进行有限重试；持续无权限或占用仍明确报错并保留旧文件，不删除旧数据以强行保存。
- 清理无调用的旧 `ccg_bots.json` 路径函数、已删除策略接口的残留注释、未使用的头文件和旧版 Windows 套接字库链接；网络测试移除多余的凭证系统库链接。
- 保留实际使用的 Qt、curl、simdjson、mbedcrypto，以及仍有界面入口的手动模式策略。统一 CMake、依赖清单和 README 版本，发布检查拒绝版本不一致。

## 更新与验证

新增离线回归覆盖杠杆超时后已生效、查询失败、有限重试耗尽、错误码拒绝、中文品种、信号失效、重算仓位、换仓、账本等待期间撤销入场，以及利润购买期间暂停、在途委托和参数修改。已有仓位、硬止损、成交核对和断点恢复继续执行原保护流程。

本次构建和发布不修改正在运行的实盘程序、配置、数据或交易所委托。更新时退出旧程序并备份完整数据目录，再替换程序及必要运行文件；保留原数据，不要用空 `data/` 覆盖旧目录，也不要同时运行两个实例管理同一账户。验证使用离线模拟接口，不代表真实交易所成交验收或策略收益保证。
