# v1.4.6 平仓重试与硬止损核对

平仓回报不明时，程序按原订单号查询。即使重启，也会继续核对在途委托。交易所曾确认接单或部分成交时，后续单次查无记录会继续触发核对。需要重新提交时，引擎重新评估退出条件，并按剩余仓量处理。

等待回报和部分成交期间，程序保留已有硬止损。运行日志列出保护单号、登记触发价和距交易所最近一次确认的时间。重启后若只有本地登记记录，日志会注明尚待交易所确认。

相同平仓失败会合并显示，日志保留可取得的 HTTP 状态、网络错误码、交易所错误码和原单查询结果。最终成交时，日志汇总本次持仓的平仓提交次数和用时。

RAVEUSDT 模拟回归覆盖连续 13 次查无订单、第 14 次在第 39 秒确认全部成交的过程，并检查硬止损仅在确认平仓后撤销。另有延迟回报、部分成交及重启恢复用例。
