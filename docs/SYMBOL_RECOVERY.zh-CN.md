# 中文品种行情与旧存档恢复

修复后的品种处理只转换 ASCII 英文字母，保留中文 UTF-8 字节，不依赖操作系统字符环境。正确名称的原有断点、再入场等待、止损和委托编号原样恢复，仍须通过启动对账和行情补齐。

## 核对副本

`tools/repair_symbol_state.py` 是离线辅助工具，不访问账户或发送订单。用交易所完整 `exchangeInfo` 列表，逐个计算旧版本会产生的乱码，只接受唯一匹配。工具默认只报告；指定 `--output` 时生成待核对副本与原文件的字节级备份，不替换正在运行的文件。

仅处理确认空仓、没有未决委托/保护单/风险预留的条目。还必须提供完整的持仓快照及合并后的普通、条件委托快照，检查目标品种没有敞口；不能把接口失败当成空列表，也不能只提供普通委托列表。快照中的身份、账户、完整性和时效需要核对，历史快照不能证明现在无仓。该工具不自动修复有持仓、未知委托、重复条目或名称不能唯一匹配的记录，这些情况需要先核对交易所归属。

```text
python3 tools/repair_symbol_state.py --state sar_bots.json --exchange-info exchange-info.json --positions positions.json --open-orders all-open-orders.json
```

确认输入后，在同一命令后加 `--output sar_bots.reviewed.json` 生成副本，备份为 `sar_bots.reviewed.json.original.bak`。副本只改品种名称，原有监控进度、止损线、再入场时间和其他字段均保留。工具拒绝覆盖已有输出或任何输入。

替换前先完成持仓/委托核对，并确认程序已停止写入状态文件。逐项审核副本，再备份和替换；不要把日志截图中的空仓状态当成当前账户证明。恢复后确认品种名称、报价、持仓和保护单一致。不要删除整个数据目录来消除告警。

## 行情提示

- `部分行情异常：3/200`：200 个订阅中有 3 个报价不可用；悬浮显示品种及从未收到报价/距最后更新多久。
- `全部品种行情异常`：请求有响应，但订阅的品种均没有有效报价。
- `行情连续拉取失败` / `行情拉取中断`：整体请求失败或成功响应已过期。

有效报价的品种仍按各自信号和风险闸门交易，过期报价不送入策略引擎。行情告警不是全账户下单开关；已挂在交易所的硬止损独立执行，本地移动止损计算需要有效报价。
